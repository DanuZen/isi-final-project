# PT MBOIS — Final Project

Platform Terpadu Manajemen Pembelajaran, Bimbingan, dan Evaluasi Tugas Akhir & Proyek.

## Repository
- **GitHub**: [https://github.com/DanuZen/isi-final-project](https://github.com/DanuZen/isi-final-project)
- **Tech Stack**: Next.js (App Router), TypeScript, Tailwind CSS

## Memulai Pengembangan

Masuk ke direktori `frontend`:
```bash
cd frontend
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.
